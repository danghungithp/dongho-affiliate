# Dongho Affiliate Frontend

React + TailwindCSS frontend for the Dongho Affiliate web app.

## Scripts

- `npm start` — Start dev server
- `npm run build` — Build for production

## Features
- Responsive product grid
- Filters (brand, style, price)
- Shopee affiliate links
- Excel import page
- About, Contact pages

## Setup

1. `npm install`
2. `npm start`

API server must be running at `http://localhost:5000` (see backend).
