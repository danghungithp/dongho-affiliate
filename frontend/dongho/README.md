# Đồng Hồ Affiliate Frontend

## Features
- Trang chủ: Hiển thị sản phẩm, lọc theo hãng, kiểu, giá
- Trang nhập Excel: Đăng nhập admin, upload file Excel để nhập sản phẩm
- Trang giới thiệu, liên hệ
- Đăng nhập admin: user `admin`, password `Danghungit@85`
- UI đẹp, responsive, TailwindCSS, Framer Motion

## Cấu hình
- API backend: http://localhost:5000 (cấu hình trong `.env`)
- Chạy: `npm start`

## Proxy
- Đã cấu hình proxy trong `package.json` để gọi API backend không bị CORS
